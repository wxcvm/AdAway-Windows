# 监听地址与更新方式

设置页可输入本机 IPv4 / IPv6；留空时使用“所有网卡”开关。显式 IP 优先于开关。
输入停止约 600 毫秒后自动检测，也可点击检测按钮。检查 HTTP、HTTPS 端口范围、重复与管理端口冲突、本机地址、系统保留端口，以及 IPv4 / IPv6 TCP 监听进程。
当前进程占用会单独显示 PID，允许保存并重启；其他进程占用或检测失败会阻止保存。
检测只是当时的状态，重启前其他程序仍可能抢占端口；启动结果以概览的真实监听表为准。
管理接口保持回环地址。指定自定义 IP 时不再暗中增加 127.0.0.1 的 80/443 兼容监听。
配置写入使用同目录暂存、刷新和原子替换；失败保留旧文件。快捷方式和重启入口读取保存的设置。
备用端口按钮只填入草稿并检测，不再未经检查保存并强制重启。

原“用便携包更新”按钮实际只是持久化 `update_mode=portable` 并检查新版本，名称容易误解。
现在“更新方式”可在自动与 ZIP 覆盖间切换，显示当前状态，保存失败有反馈；点击“检查更新”才开始检查。
自动模式优先安装器，安装器无法启动时下载同一版本的 ZIP 并原地替换。
ZIP 模式直接选 ZIP，避免先下载安装器再下载 ZIP。两者都要求有新版本与正确 SHA-256；不会强制重装当前版本。
预览发行使用同一安装标识；它不推进稳定更新源。

维护按钮也按真实行为显示：原“清空统计”实际执行磁盘保存，现名为“立即保存统计”；它不会清零。
控制命令现在读取完整 HTTP 响应头和状态码，不再把 socket 发送成功当成操作成功。
订阅重载、策略加载和 CA 轮换会显示服务端拒绝或未确认的状态。完成 CA 文件轮换不会自动移除 Windows 信任库中的旧证书。

验收范围：CI 真实套接字占用检测、native 输入验证、主程序自定义地址启动、GUI 控件操作、完整 Windows 构建。
日常主机的网络接管和真实设备恢复仍需单独验收。
