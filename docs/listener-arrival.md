# AdGuard DNS 与请求到达检测

诊断窗口显示当前管理回执、IPv4/IPv6 HTTP/HTTPS、系统 DNS 或 UDP 占用阶段，并提供“取消检测”。运行中可以立即关闭窗口；取消和重开不会启动并行报告任务。取消后保留上次完成的报告，进度显示在独立状态行，不以中间文本覆盖旧结果。完成只表示本次诊断结束，具体成功与否仍逐项列明。

HTTP、HTTPS 和 DNS 的等待路径最多每 50ms 检查一次取消。HTTP/DNS 保留两秒预算，HTTPS 网络等待也使用两秒预算；HTTP/HTTPS 回执保持 4096 字节上限。同步系统证书或端点枚举调用在返回后停止后续步骤，不强制终止系统 API。取消只停止等待和后续探测；已交给系统的 DNS 查询可能继续，保留原来最多一个未完成解析线程的限制，重试会明确报告仍忙。

后台任务单独拥有配置、取消/完成事件和结果内存。窗口销毁及 WM_QUIT/GetMessage 错误路径都会取消并释放窗口引用；worker 从不持有窗口指针或 HWND，不向旧窗口发送完成消息。现有公开 receipt/TLS/report 入口继续兼容，默认无取消 token。

进程存在不能证明 WFP/代理接管，系统 DNS 返回也可能来自缓存或 Hosts；具体 AdGuard 规则及语法类别以其日志为准。
报告标出本次实际检测的 HTTP／HTTPS 端口。DNS 只返回地址，不映射端口；自定义端口的回执不能证明普通客户端默认 HTTP/80 或 HTTPS/443 可达，报告会单独提示这个边界。
公网或不匹配的 DNS 返回只显示结果，不建立到公网源站的连接。请求不经过系统 HTTP 代理，不跟随重定向；每次本机 HTTP 连接最多 2 秒/4096 字节。
沿用 Winsock GetAddrInfoW 的系统 DNS 与 2 秒等待预算，最多一个未完成的解析线程；超时任务保留堆上下文到系统完成，不产生无界线程或悬空回调。沿用 BCrypt 生成随机 128 位 nonce，没有新建通用转发器、DNS 上游或网络接管。

生产 native 入口的固定 GET /adaway-listener-probe/<32 hex> 在任何转发前处理，只返回固定格式 nonce、no-store；拒绝非法 nonce 与其他方法。
它是公开无状态回执，不是认证，不返回内部配置/统计/浏览记录，不改变规则或用户排行。当前 HTTPS、双协议与启动选项见 [监听生命周期](listener-lifecycle.md)；其他应用路径仍需独立验收。

# 保存并重新启动

“保存并重启”先原子保存配置、停止本进程拥有的服务器并等待清理，再释放本安装的单实例句柄并创建新进程。新进程从同一份 INI 读取监听地址和端口；资源目录参数保留 UTF-8 路径和末尾反斜杠。创建失败或新进程立即退出会提示错误，不显示启动成功。开机启动项修复失败会提示，但不阻止使用已保存设置重新打开。

仅附着外部服务器的面板显示“保存并重新打开”：只重新打开本安装，不停止或改变附着的外部进程。将本安装的 HTTP、HTTPS 及管理端口配置为空闲端口后，可以启动自己的服务器。保存失败保留原配置，继续运行当前服务器。
